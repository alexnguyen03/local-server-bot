# ADR-0003: Flow 1: CI builds to GHCR, LS mirrors to CS with skopeo

Status: Accepted (2026-10)

## Context

Originally GitHub Actions built and pushed images to GHCR. CS can't reach GHCR, so the image has to be moved into the internal registry some other way.

## Decision

LS uses `skopeo copy` from GHCR to the internal registry on CS (`CS_REGISTRY`), skipping the copy if the digests already match. `resolve-tag.sh` finds the latest tag per `TRACK_TAG`. CI's `notify` job sends `/deploy_<x>_uat` into the group through the CI bot.

## Consequences

- skopeo needs no Docker daemon and no insecure-registries configuration.
- Depends on GitHub Actions quota (ADR-0006 is the fallback once it runs out).
- The auto-poll (ADR-0005) still catches a new tag even if CI never sends the command.

## Alternatives considered or deferred

- `docker pull/push` through the daemon: would need the daemon configured for an insecure registry.
