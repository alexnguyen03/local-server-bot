# ADR-0010: Security items deferred for now

Status: Accepted (2026-10)

## Context

Building on LS runs the repo's code on the user's personal machine, the same machine that holds the tokens.

## Decision

Not splitting the builder off into its own WSL distro yet. Accepting that the registry password travels over HTTP within the internal network/VPN. Tokens live in `.secrets` (chmod 600); git auth goes through `GIT_CONFIG_*` so it never shows up in argv. The bot never accepts a free-form argument.

## Consequences

- Backlog items: a separate builder distro, HTTPS for the CS registry, revoking the PAT that leaked, rotating the `ci-bot`/`ci` passwords.
- Never expose Jenkins/Dockhand outside the VPN.

## Alternatives considered or deferred

- Splitting the builder off right away: the user chose to defer it for now.
